ABELLE STUDIOS WEBSITE UPDATE

What is inside:
- src/App.jsx = the new simple elegant React website
- public/assets/ = the SVG price guide assets used by the website

How to install in your existing Vite React project:
1. Open your abelle-studios folder.
2. Replace your current src/App.jsx with the App.jsx from this zip.
3. Copy the entire assets folder into your existing public folder.
   Final path should look like: public/assets/personal-portraits.svg
4. In your terminal, inside abelle-studios, run:
   npm run dev
5. If it looks good, push to GitHub:
   git add .
   git commit -m "redesign abelle studios website"
   git push

Vercel will redeploy automatically.
