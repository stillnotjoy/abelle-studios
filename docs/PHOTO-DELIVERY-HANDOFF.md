## Install in Google Apps Script

1. Create a new script file named **ViewingReady**. Paste the complete contents of `scripts/ViewingReady.gs`. Do not replace the existing Code.gs or its existing handlers.
2. In the existing **doGet(e)**, immediately AFTER its secret authentication check and BEFORE any calendar lookup, insert:

```js
if (action === "viewing_ready_capabilities") {
  return jsonResponse(viewingReadyCapabilities_());
}
```

3. In the existing **doPost(e)**, immediately AFTER its secret authentication check and BEFORE the fallback `createPaidBookingFromPayload(payload)`, insert:

```js
if (payload.action === "notify_viewing_ready") {
  return jsonResponse(notifyViewingReady_(payload));
}
```

4. In **Project Settings → Script Properties**, confirm existing `PHILSMS_API_TOKEN` and `PHILSMS_SENDER_ID`, which the installed feature reuses. Optional overrides are `VIEWING_READY_PHILSMS_TOKEN` and `VIEWING_READY_PHILSMS_SENDER`. Never paste these values into chat, Git or this file.
5. Under **Services → +**, add **Drive API**, version **v3**, identifier **Drive**. If the script uses a standard Google Cloud project, enable the Google Drive API there too. See https://developers.google.com/apps-script/guides/services/advanced . The API grants writer/editor access to only the booking email and suppresses Google's separate sharing email.
6. Run **authorizeViewingReady** once from the function dropdown, using the account that owns/manages the client folders, and approve the requested scopes. This function reads a file listing/quota; it sends no messages. If your appsscript.json already declares explicit oauthScopes, preserve existing scopes and include `https://www.googleapis.com/auth/drive`, `https://www.googleapis.com/auth/script.send_mail`, `https://www.googleapis.com/auth/script.external_request`.
7. Save, then **Deploy → Manage deployments → existing web app → pencil → New version → Deploy**. Keep the existing URL and execute-as account. Do not create a separate deployment URL unless the website configuration is updated too.
